# 2025년 5월 8일 학습 기록

이 디렉토리는 컴퓨터 비전 라이브러리인 `OpenCV`의 기초부터 심화 기능까지 단계별로 학습하는 실습 코드를 포함합니다. 각 챕터(`ch`)별로 나누어진 Python 스크립트를 통해 이미지 및 비디오 처리의 핵심 기술을 익힙니다.

## 📝 학습 내용 요약

- **`ch2`**: `OpenCV`의 가장 기본적인 기능을 다룹니다. 이미지를 불러오고, 화면에 표시하며, 파일로 저장하는 기본적인 이미지 입출력(I/O) 작업을 학습합니다. 또한, 이미지의 속성(크기, 채널 등)을 확인하는 방법을 실습합니다.

- **`ch3`**: 이미지의 기본적인 연산과 변형 기술을 학습합니다. 그레이스케일 변환, 이미지의 특정 영역(ROI, Region of Interest) 잘라내기, 색상 공간 변경(예: BGR to RGB), 이미지 합성과 같은 기본적인 이미지 처리 기법을 다룹니다.

- **`ch4`**: 도형 그리기, 텍스트 추가 등 이미지에 시각적 요소를 더하는 방법을 학습합니다. 선, 사각형, 원과 같은 도형을 그리고, 이미지에 원하는 텍스트를 삽입하는 방법을 실습하여 이미지에 주석을 달거나 정보를 시각적으로 표현하는 능력을 기릅니다.

## 💡 주요 학습 기술

- **라이브러리**: OpenCV-Python, NumPy
- **핵심 개념**:
    - 이미지 및 비디오 I/O
    - 색상 공간 (BGR, GRAY, HSV)
    - 기하학적 변환 (크기 조절, 자르기)
    - 이미지 스레시홀딩
    - 비트와이즈 연산 및 마스킹
