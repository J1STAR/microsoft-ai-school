JavaScript 스코프(Scope)와 클로저(Closure)

스코프는 변수와 함수에 접근할 수 있는 범위를 결정합니다. JavaScript에는 전역 스코프, 함수 스코프, 블록 스코프가 있습니다.

1. 전역 스코프 (Global Scope)

코드의 가장 바깥 영역에 정의된 변수나 함수는 전역 스코프에 속합니다. 전역 변수는 코드 어디에서든 접근할 수 있지만, 남용하면 변수 이름 충돌이나 의도치 않은 변경을 유발할 수 있어 주의해야 합니다. 

const globalVar = "나는 전역 변수입니다.";

function showGlobal() {
  console.log(globalVar); // "나는 전역 변수입니다."
}
showGlobal();
console.log(globalVar); // "나는 전역 변수입니다."

2. 함수 스코프 (Function Scope)

var 키워드로 선언된 변수는 함수 내에서만 유효한 함수 스코프를 가집니다. 함수 외부에서는 이 변수에 접근할 수 없습니다. 

function functionScopeTest() {
  var functionScopedVar = "나는 함수 스코프 변수입니다.";
  console.log(functionScopedVar); // "나는 함수 스코프 변수입니다."
}

functionScopeTest();
// console.log(functionScopedVar); // ReferenceError!

3. 블록 스코프 (Block Scope)

ES6에서 도입된 let과 const 키워드로 선언된 변수는 중괄호 {}로 둘러싸인 블록(예: if, for, while 등) 내에서만 유효한 블록 스코프를 가집니다. 이는 변수의 유효 범위를 최소화하여 더 예측 가능하고 안정적인 코드를 작성하게 돕습니다. 

if (true) {
  let blockScopedLet = "나는 블록 스코프(let) 변수입니다.";
  const blockScopedConst = "나는 블록 스코프(const) 상수입니다.";
  var legacyVar = "나는 함수 스코프(var)입니다."; // var는 블록 스코프를 무시함

  console.log(blockScopedLet);
  console.log(blockScopedConst);
}

// console.log(blockScopedLet);   // ReferenceError!
// console.log(blockScopedConst); // ReferenceError!
console.log(legacyVar);          // "나는 함수 스코프(var)입니다."

4. 렉시컬 스코프와 클로저 (Lexical Scope & Closure)

렉시컬 스코프는 함수를 어디서 '선언'했는지에 따라 상위 스코프가 결정되는 방식입니다. 클로저는 이러한 특성을 이용하여, 함수가 자신의 선언 환경(상위 스코프)을 기억하고, 그 환경 밖에서 호출될 때에도 해당 환경의 변수에 접근할 수 있게 하는 기능입니다.

클로저의 핵심: 함수가 자신이 태어난 환경(Lexical Environment)을 기억하고, 그 환경 밖에서도 계속 접근할 수 있는 것. 

function createCounter() {
  let count = 0; // 자유 변수. createCounter의 환경에 속합니다.

  // 아래 반환되는 함수가 바로 클로저입니다.
  // 이 함수는 자신이 선언된 환경의 'count' 변수를 기억합니다.
  return function() {
    count++;
    console.log(count);
  };
}

const counter1 = createCounter(); // counter1은 자신만의 독립된 'count'를 가집니다.
const counter2 = createCounter(); // counter2도 자신만의 독립된 'count'를 가집니다.

console.log("카운터 1:");
counter1(); // 1
counter1(); // 2

console.log("카운터 2:");
counter2(); // 1

// 외부에서 'count' 변수에는 직접 접근할 수 없습니다. -> 데이터 은닉
// 각 카운터는 자신만의 상태를 유지합니다. -> 상태 유지
