TypeScript 제네릭 (Generics)

제네릭은 컴포넌트(함수, 클래스, 인터페이스 등)가 다양한 타입을 처리할 수 있도록 하면서도 타입 안정성을 잃지 않게 해주는 강력한 기능입니다. 하나의 코드로 여러 타입을 지원함으로써 코드의 재사용성을 극대화합니다.

1. 제네릭의 기본: Identity 함수

제네릭의 가장 기본적인 예는 'identity' 함수입니다. 이 함수는 어떤 타입의 인자를 받으면 동일한 타입의 값을 반환합니다. 제네릭을 사용하면 any 타입을 사용했을 때 잃게 되는 타입 정보를 그대로 보존할 수 있습니다. 

// T는 타입 변수(type variable)로, 함수를 사용하는 시점에 타입이 결정됩니다.
function identity<T>(arg: T): T {
    return arg;
}

// 사용 방법 1: 타입 인수를 명시적으로 전달
let output1 = identity<string>("myString");

// 사용 방법 2: 컴파일러가 타입을 추론 (type argument inference)
let output2 = identity(123);

console.log(typeof output1); // "string"
console.log(typeof output2); // "number"

2. 제네릭 인터페이스 (Generic Interfaces)

인터페이스에 제네릭을 적용하여 다양한 타입에 대응하는 유연한 구조를 정의할 수 있습니다. 

interface GenericIdentityFn<T> {
    (arg: T): T;
}

function identity<T>(arg: T): T {
    return arg;
}

let myIdentity: GenericIdentityFn<number> = identity;
console.log(myIdentity(100)); // 100

3. 제네릭 클래스 (Generic Classes)

클래스에 제네릭을 사용하면, 클래스의 인스턴스가 특정 타입에 종속되도록 만들 수 있습니다. 이를 통해 타입 안정성을 갖춘 재사용 가능한 클래스를 설계할 수 있습니다. 

class GenericNumber<T> {
    zeroValue: T;
    add: (x: T, y: T) => T;
}

// 숫자 타입으로 사용하는 경우
let myGenericNumber = new GenericNumber<number>();
myGenericNumber.zeroValue = 0;
myGenericNumber.add = function(x, y) { return x + y; };
console.log(myGenericNumber.add(5, 10)); // 15

// 문자열 타입으로 사용하는 경우
let stringNumeric = new GenericNumber<string>();
stringNumeric.zeroValue = "";
stringNumeric.add = function(x, y) { return x + y; };
console.log(stringNumeric.add("Hello, ", "World!")); // "Hello, World!"

4. 제네릭 제약 조건 (Generic Constraints)

때로는 제네릭 타입이 특정 프로퍼티나 구조를 가지고 있다고 보장해야 할 때가 있습니다. 이 때 extends 키워드를 사용하여 '제약 조건'을 추가할 수 있습니다. 

interface Lengthwise {
    length: number;
}

// T는 이제 Lengthwise 인터페이스를 만족하는 타입만 가능합니다.
// 즉, .length 프로퍼티를 반드시 가져야 합니다.
function loggingIdentity<T extends Lengthwise>(arg: T): T {
    console.log(arg.length); // .length가 존재함을 보장받음
    return arg;
}

loggingIdentity("hello"); // string은 .length가 있으므로 성공
loggingIdentity([1, 2, 3]); // array는 .length가 있으므로 성공
loggingIdentity({ length: 10, value: 3 }); // 객체도 .length가 있으므로 성공
// loggingIdentity(123); // 오류: number에는 .length 프로퍼티가 없음

5. 제약 조건에서 타입 매개변수 사용

한 타입 매개변수가 다른 타입 매개변수의 키(key) 중 하나를 따르도록 제약할 수 있습니다. keyof 연산자를 사용하면 객체의 모든 키를 문자열 리터럴 유니언 타입으로 얻을 수 있습니다. 

// T는 객체, K는 T 객체의 키 중 하나여야 합니다.
function getProperty<T, K extends keyof T>(obj: T, key: K) {
    return obj[key];
}

let vehicle = {
    brand: "Toyota",
    model: "Camry",
    year: 2022
};

console.log(getProperty(vehicle, "brand")); // "Toyota"
console.log(getProperty(vehicle, "year"));  // 2022

// console.log(getProperty(vehicle, "color")); 
// 오류: Argument of type '"color"' is not assignable to parameter of type '"brand" | "model" | "year"'.
