TypeScript 기본 개념

TypeScript는 JavaScript에 정적 타입(static types)을 추가한 슈퍼셋(superset) 언어입니다. 개발 단계에서 타입 오류를 미리 잡아 안정성을 높이고, 코드 자동완성 및 가독성을 향상시켜 대규모 애플리케이션 개발에 유리합니다.

1. 기본 타입 (Basic Types)

TypeScript는 JavaScript의 기본 타입 외에 추가적인 타입을 제공하여 변수나 함수의 값을 명확하게 정의할 수 있습니다.

// Boolean
let isDone: boolean = false;

// Number (정수, 실수 모두 포함)
let decimal: number = 6;
let hex: number = 0xf00d;

// String
let color: string = "blue";
color = 'red';

// Array
let list: number[] = [1, 2, 3];
let genericList: Array = [1, 2, 3];

// Tuple (고정된 수의 요소 타입, 순서까지 정의)
let x: [string, number];
x = ["hello", 10]; // 성공
// x = [10, "hello"]; // 오류

// Enum (열거형)
enum Color {Red, Green, Blue}
let c: Color = Color.Green; // 1

enum ColorName {Red = 1, Green = 2, Blue = 4}
let colorName: string = ColorName[2]; // 'Green'

// Any (모든 타입 허용, 타입 검사 비활성화)
let notSure: any = 4;
notSure = "maybe a string instead";

// Void (주로 반환 값이 없는 함수의 반환 타입으로 사용)
function warnUser(): void {
    console.log("This is my warning message");
}

// Null and Undefined
let u: undefined = undefined;
let n: null = null;

// Never (절대 발생할 수 없는 값의 타입)
function error(message: string): never {
    throw new Error(message);
}

2. 인터페이스 (Interfaces)

인터페이스는 객체의 구조를 정의하는 데 사용됩니다. 객체가 특정 구조를 따르도록 강제하여 코드의 일관성을 유지합니다.

interface LabeledValue {
    label: string;
}

function printLabel(labeledObj: LabeledValue) {
    console.log(labeledObj.label);
}

let myObj = {size: 10, label: "Size 10 Object"};
printLabel(myObj); // 성공 (덕 타이핑)

// 선택적 프로퍼티 (Optional Properties)
interface SquareConfig {
    color?: string;
    width?: number;
}

// 읽기 전용 프로퍼티 (Readonly Properties)
interface Point {
    readonly x: number;
    readonly y: number;
}
let p1: Point = { x: 10, y: 20 };
// p1.x = 5; // 오류!

// 함수 타입
interface SearchFunc {
    (source: string, subString: string): boolean;
}
let mySearch: SearchFunc;
mySearch = function(src, sub) {
    return src.search(sub) > -1;
}

3. 클래스 (Classes)

TypeScript는 ES6 클래스 문법을 지원하며, 접근 제한자(public, private, protected)와 같은 객체 지향 기능을 추가로 제공합니다.

class Animal {
    private name: string; // private 멤버
    public constructor(theName: string) {
        this.name = theName;
    }
    public move(distanceInMeters: number = 0) {
        console.log(`${this.name} moved ${distanceInMeters}m.`);
    }
}

class Snake extends Animal {
    constructor(name: string) {
        super(name);
    }
    move(distanceInMeters = 5) {
        console.log("Slithering...");
        super.move(distanceInMeters);
    }
}

let sam = new Snake("Sammy the Python");
sam.move();

4. 함수 (Functions)

함수의 매개변수와 반환 값에 타입을 지정하여 의도를 명확히 하고 실수를 방지할 수 있습니다.

// 이름 있는 함수
function add(x: number, y: number): number {
    return x + y;
}

// 함수 표현식
let myAdd = function(x: number, y: number): number { return x + y; };

// 선택적 및 기본 매개변수
function buildName(firstName: string, lastName: string = "Smith") {
    return firstName + " " + lastName;
}

// 나머지 매개변수 (Rest Parameters)
function buildNameRest(firstName: string, ...restOfName: string[]) {
  return firstName + " " + restOfName.join(" ");
}

5. 제네릭 (Generics)

제네릭은 함수나 클래스에서 사용할 타입을 미리 지정하지 않고, 실제 사용할 때 타입을 지정할 수 있게 하는 기능입니다. 코드 재사용성을 크게 높여줍니다.

function identity(arg: T): T {
    return arg;
}

let output1 = identity("myString");
let output2 = identity(100);

// 제네릭 인터페이스
interface GenericIdentityFn {
    (arg: T): T;
}
let myIdentity: GenericIdentityFn = identity;

// 제네릭 클래스
class GenericNumber {
    zeroValue: T;
    add: (x: T, y: T) => T;
}

let myGenericNumber = new GenericNumber();
myGenericNumber.zeroValue = 0;
myGenericNumber.add = function(x, y) { return x + y; };

6. 고급 타입 (Advanced Types)

여러 타입을 조합하여 더 복잡하고 유연한 타입을 만들 수 있습니다.

// 유니언 타입 (Union Types)
function padLeft(value: string, padding: string | number) {
    if (typeof padding === "number") {
        return Array(padding + 1).join(" ") + value;
    }
    if (typeof padding === "string") {
        return padding + value;
    }
    throw new Error(`Expected string or number, got '${padding}'.`);
}

// 타입 가드 (Type Guards)
interface Bird {
    fly(): void;
    layEggs(): void;
}

interface Fish {
    swim(): void;
    layEggs(): void;
}

function getSmallPet(): Fish | Bird {
    // ...
    return { fly: () => {}, layEggs: () => {} };
}

let pet = getSmallPet();
if ((pet as Bird).fly) { // 타입 단언을 통한 가드
    (pet as Bird).fly();
} else {
    (pet as Fish).swim();
}

// 타입 별칭 (Type Aliases)
type Name = string;
type NameResolver = () => string;
type NameOrResolver = Name | NameResolver;

function getName(n: NameOrResolver): Name {
    if (typeof n === "string") {
        return n;
    } else {
        return n();
    }
}
