JavaScript 모듈 (ES6 Modules)

ES6(ECMAScript 2015)에서 도입된 모듈 시스템은 코드를 재사용 가능한 조각으로 구성하고, 전역 스코프의 오염을 방지하며, 의존성을 명확하게 관리할 수 있도록 돕습니다.

모듈의 기본 개념

모듈은 파일 단위로 코드를 분리하는 방식입니다. 한 파일에서 기능을 내보내고(export), 다른 파일에서 그 기능을 가져와(import) 사용할 수 있습니다.

1. 기능 내보내기 (Export)

이름 있는 내보내기 (Named Exports)

export 키워드를 사용하여 변수, 함수, 클래스를 개별적으로 내보낼 수 있습니다. 한 파일에서 여러 개를 내보낼 수 있습니다. 

// 파일: math.js

export const PI = 3.14159;

export function add(a, b) {
  return a + b;
}

export class Calculator {
  multiply(a, b) {
    return a * b;
  }
}

기본 내보내기 (Default Export)

export default를 사용하여 모듈에서 단 하나의 값만 내보낼 수 있습니다. 파일 당 한 번만 사용 가능하며, 주로 해당 모듈을 대표하는 하나의 기능을 내보낼 때 사용합니다. 

// 파일: logger.js

export default function log(message) {
  console.log(`[LOG] ${message}`);
}

2. 기능 가져오기 (Import)

이름 있는 가져오기 (Named Imports)

중괄호 {} 안에 가져올 기능의 이름을 명시하여 가져옵니다. as 키워드를 사용하여 이름을 바꿔서 사용할 수도 있습니다. 

// 파일: main.js
import { PI, add as sum, Calculator } from './math.js';

console.log(PI); // 3.14159
console.log(sum(5, 3)); // 8
const calc = new Calculator();
console.log(calc.multiply(4, 5)); // 20

기본 가져오기 (Default Import)

중괄호 없이 원하는 변수 이름으로 가져올 수 있습니다.

// 파일: main.js
import printLog from './logger.js';

printLog("애플리케이션 시작!"); // [LOG] 애플리케이션 시작!

모듈 전체 가져오기

* as 구문을 사용하여 모듈의 모든 named export를 하나의 객체로 가져올 수 있습니다. 

// 파일: main.js
import * as mathUtils from './math.js';

console.log(mathUtils.PI); // 3.14159
console.log(mathUtils.add(10, 20)); // 30

모듈 사용 방법

브라우저 환경에서 ES6 모듈을 사용하려면 <script> 태그에 type="module" 속성을 추가해야 합니다. 

<script type="module" src="main.js"></script>

Node.js 환경에서는 기본적으로 CommonJS 모듈 시스템을 사용하지만, package.json에 "type": "module"을 추가하거나 파일 확장자를 .mjs로 사용하여 ES6 모듈을 사용할 수 있습니다.
