JavaScript 심볼 (Symbol)

심볼은 ES6에서 도입된 7번째 데이터 타입으로, 유일하고 변경 불가능한(immutable) 원시 값입니다. 주로 객체 속성의 충돌을 방지하기 위한 고유한 키(key)를 만드는 데 사용됩니다.

참고 자료:

  • MDN - Symbol
  • javascript.info - 심볼형

1. 심볼 생성 및 기본 특징

Symbol() 함수를 호출하여 심볼을 생성합니다. new 연산자와 함께 사용할 수 없습니다. 심볼은 항상 고유한 값을 가지므로, 설령 설명(description)이 같더라도 두 심볼은 다른 값으로 취급됩니다. 

const sym1 = Symbol();
const sym2 = Symbol("description"); // 디버깅을 위한 설명

console.log(typeof sym1); // "symbol"

// 설명이 같아도 두 심볼은 다릅니다.
const sym3 = Symbol("description");
console.log(sym2 === sym3); // false

2. 고유한 객체 프로퍼티 키로 사용

심볼을 객체의 프로퍼티 키로 사용하면, 다른 어떤 문자열 키와도 충돌하지 않는 것을 보장할 수 있습니다. 이를 통해 외부 코드에 의해 의도치 않게 프로퍼티가 덮어쓰여지는 것을 방지할 수 있습니다.

심볼로 된 키는 for...in 루프나 JSON.stringify와 같은 일반적인 열거(enumeration) 대상에서 제외됩니다. 이는 객체의 내부적인 메타데이터를 저장하는 데 유용합니다. 

const idSymbol = Symbol("id");

const user = {
  name: "홍길동",
  age: 30,
  [idSymbol]: "user-12345" // 계산된 프로퍼티 이름 문법 사용
};

console.log(user[idSymbol]); // "user-12345"

// 일반적인 열거에서는 제외됨
console.log(Object.keys(user)); // ['name', 'age']
console.log(JSON.stringify(user)); // {"name":"홍길동","age":30}

// 심볼 키를 얻으려면 다음 메서드를 사용합니다.
console.log(Object.getOwnPropertySymbols(user)); // [Symbol(id)]
console.log(Reflect.ownKeys(user)); // ['name', 'age', Symbol(id)]

3. 전역 심볼 레지스트리

Symbol.for(key)는 '전역 심볼 레지스트리'를 사용하여 심볼을 생성하거나 가져옵니다. 동일한 키에 대해서는 항상 동일한 심볼을 반환하므로, 여러 파일이나 다른 영역(realm)에서 같은 심볼을 공유해야 할 때 유용합니다. 

const globalSym1 = Symbol.for("shared_symbol");
const globalSym2 = Symbol.for("shared_symbol");

console.log(globalSym1 === globalSym2); // true

// Symbol.keyFor(symbol)로 전역 심볼의 키를 얻을 수 있습니다.
console.log(Symbol.keyFor(globalSym1)); // "shared_symbol"

4. 잘 알려진 심볼 (Well-known Symbols)

JavaScript는 내부 알고리즘에 사용되는 '잘 알려진 심볼(Well-known Symbols)'들을 Symbol 객체의 정적 프로퍼티로 제공합니다. 개발자는 이 심볼들을 사용하여 객체의 기본 동작을 재정의할 수 있습니다.

예를 들어, Symbol.iterator는 객체를 이터러블(iterable)하게 만들어 for...of 루프에서 사용할 수 있게 합니다. 

const myIterable = {
  data: [10, 20, 30],
  // `for...of` 루프는 이 Symbol.iterator 메서드를 호출합니다.
  [Symbol.iterator]: function* () {
    for (const item of this.data) {
      yield item;
    }
  }
};

for (const value of myIterable) {
  console.log(value); // 10, 20, 30 순서로 출력
}

// Symbol.hasInstance는 instanceof 연산자의 동작을 재정의합니다.
class CustomNumber {
    static [Symbol.hasInstance](instance) {
        return typeof instance === 'number';
    }
}
console.log(123 instanceof CustomNumber); // true
