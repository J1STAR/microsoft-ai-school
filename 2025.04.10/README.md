## 💡 주요 코드 예시

### 숫자 자료형 확인

Python이 다루는 다양한 종류의 숫자 데이터 타입을 확인하는 코드입니다.

```python
# 숫자 자료형
print(f"""\
{type(10)}
{type(3.14)}
{type(3.14e10)}
{type(0o10)}
{type(0x10)}
{type(0b10)}
{type(3 + 4j)}
""")
```

### 몫과 나머지 연산자 활용

정수 나누기 연산자(`//`)와 나머지 연산자(`%`)를 활용하여 숫자의 각 자릿수를 분리하는 방법을 보여주는 코드입니다.

```python
# //, % 연산자
n = 1234
print(f"""\
{n // 1000}
{n // 100 % 10}
{n // 10 % 10}
{n % 10}
""")
```
