# 2025년 5월 21일 학습 기록

이 디렉토리는 "밑바닥부터 시작하는 딥러닝" 교재의 실습 코드를 포함하고 있으며, `TensorFlow`나 `PyTorch`와 같은 딥러닝 프레임워크 없이 오직 `NumPy`만을 사용하여 신경망(Neural Network)의 핵심 원리를 구현하고 학습하는 데 중점을 둡니다.

## 📝 학습 내용 요약

`notebooks/DL1_20240707/`와 `notebooks/DL3_20241006/` 디렉토리는 교재의 챕터별 실습 코드로 구성되어 있습니다.

- **`ch01` ~ `ch02`**: Python 기초와 `NumPy`, `Matplotlib` 사용법을 복습하고, 퍼셉트론(Perceptron)의 개념과 AND, OR, NAND 게이트 구현을 통해 신경망의 기본 단위를 학습합니다.
- **`ch03`**: 신경망의 순전파(forward propagation) 과정을 다룹니다. 활성화 함수(Sigmoid, ReLU)의 역할과 다차원 배열을 이용한 신경망 계산을 구현합니다. MNIST 손글씨 숫자 데이터셋을 사용하여 첫 번째 이미지 분류 신경망을 구축합니다.
- **`ch04`**: 신경망의 학습 원리인 오차역전파법(Backpropagation)을 이해하기 위해, 수치 미분을 통한 기울기(gradient) 계산 방법을 학습하고, 이를 이용한 간단한 신경망 학습을 구현합니다.
- **`ch05`**: 오차역전파법을 계산 그래프(Computational Graph)를 통해 효율적으로 구현하는 방법을 학습합니다. 곱셈, 덧셈 등 간단한 연산 계층(layer)부터 Sigmoid, Affine, Softmax 계층까지 직접 구현하여 오차역전파의 원리를 체득합니다.
- **`ch06`**: 학습 관련 기술들을 다룹니다. 매개변수 최적화 방법(SGD, Adam 등), 가중치 초기값 설정, 배치 정규화(Batch Normalization), 과적합 방지를 위한 드롭아웃(Dropout) 등 모델의 성능을 높이는 다양한 기법을 학습합니다.
- **`ch08`**: 합성곱 신경망(CNN, Convolutional Neural Network)의 원리를 학습하고, `NumPy`로 직접 구현해봅니다. 이를 통해 이미지 인식 분야에서 CNN이 어떻게 동작하는지 깊이 있게 이해합니다.
