# 2025년 4월 9일 학습 기록

이 디렉토리는 새로운 프로젝트 시작을 위한 초기 환경 설정과 웹 및 Python의 기초를 다루는 파일들을 포함합니다. HTML 파일 구조 학습, Python 코드 실행 환경 점검, 버전 관리 시스템을 위한 초기 파일 생성을 실습합니다.

## 📝 학습 내용 요약

- **HTML 기본 구조**: `index.html` 파일을 통해 웹 페이지의 기본적인 `<!DOCTYPE>`, `<html>`, `<head>`, `<body>` 구조와 제목을 나타내는 `<h1>`부터 `<h6>` 태그의 사용법을 학습합니다.
- **Python 실행 환경 점검**: `test.ipynb`와 `test.py`에서 "Hello Python"을 출력하는 간단한 코드를 실행하여, Jupyter Notebook과 기본적인 Python 스크립트 실행 환경의 작동 여부를 확인합니다.
- **기본 파일 관리**: `newfile.txt`와 같은 텍스트 파일을 생성하며 프로젝트에 파일을 추가하는 기본적인 작업을 실습합니다. 이는 버전 관리 시스템(Git) 사용을 위한 초기 단계에 해당합니다.
